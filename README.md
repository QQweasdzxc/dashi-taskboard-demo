# dashi-taskboard 離線試看版(示範資料)

這是 [chuspeeism/dashi-taskboard](https://github.com/chuspeeism/dashi-taskboard)(Apache-2.0)的**本機試看展示**,用來在決定是否採用前先看看原版看板的內容與操作。

- 開啟 Pages 網址後即可直接操作:看板、列表、甘特圖、任務詳情、新增任務、拖曳換欄、留言。
- **示範資料**:所有專案與任務都是內建範例,與任何正式系統無關。
- **儲存限制**:你在頁面上的新增與拖曳只存在你自己的瀏覽器(localStorage),不會上傳、不會同步;頁面底部有「重設示範資料」按鈕可還原。
- 原版完整功能(雲端同步、Codex/AI 整合、附件上傳、Jira)需要正式部署,此處不包含。

## 技術說明

`index.html` 是原專案前端(v1.1.27)的單檔打包,外加一段明確標示的示範資料 adapter:它在瀏覽器內攔截 `/api` 請求並以內建範例資料回應,未修改原版 UI 程式邏輯。原專案授權見 `LICENSE`。
